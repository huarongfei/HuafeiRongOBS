# HuafeiRongOBS 功能预告与现状说明

> 基于 **obs-studio 32.2.2** 源码深度定制的 Windows 多画布直播/多屏分发系统。
> 本文档面向使用者与验收者：**已能做什么、怎么用、现在有什么限制、接下来要做什么**。
> 版本：M1 + UI S1~S3 阶段（本文写作时的已提交状态）。

---

## 一、一句话定位

**一台机器 = 演出 / 会议 / 展厅 / 多机位导播的「多屏 + 多推流 + 录制」一体机。**
核心区别于原版 OBS：原版同一时刻只有**一路节目输出**；本系统引入 **画布（Canvas）** 概念，
可同时运行**多路彼此独立的输出画面**，并各自投影到不同显示器 / 推流 / 录制。

---

## 二、已完成功能（可直接试用）

### 1. 嵌入式「输出矩阵（画布）」面板
主窗口**右侧停靠坞**，不再有零散弹窗，操作集中在一处：

| 区域 | 能力 |
|---|---|
| 显示器（编号） | 自动检测所有显示器并编号：`#0 DISPLAY1 1920x1080 [主]`；接好外接屏后点"刷新"重新编号 |
| 画布列表 | 每行含 **实时缩略预览** + 名称 + 分辨率；**★ 主画布**（原 OBS 节目）常驻，不可删除/改名 |
| 画布操作 | `+ 新建画布`（弹窗填名称 + 选分辨率 1280x720 / 1920x1080 / 960x540 / 2560x1440）、`重命名`、`删除` |
| 投影 | 选画布 + 选屏编号 → `▶投影选中屏` 全屏投到该屏；`■停本画布` 只停该画布投影；`■全部` 停全部 |
| 快速上屏 | **双击画布行** = 一键投到主屏 |

### 2. 每画布独立场景集（"点哪操作哪"的第一步）
选中画布后，面板下方"场景（当前画布）"即操作**该画布**的场景：
`+场景` 新建、`切到此场景` 切换（缩略图/投影实时跟随）、`删场景` 删除、`给场景加色块` 就地加内容（按画布分辨率铺满）。

### 3. 安全区网格
选中画布 → `安全区` 开关：投影画面上叠加 **白色 90% 标题安全区** + **红色 80% 动作安全区**（LED/投影防裁切参考），
开关状态按画布记忆，新开的投影自动沿用。

### 4. 全链路持久化
状态存于 **`<当前 profile 目录>\hfr_canvases.json`**，退出后重启自动还原：
画布（名称/分辨率/是否含测试色）、**每画布的场景集与当前场景**（含测试色块内容重建）、
投影布局（画布 → 屏编号 + 屏名，换接口也能对上）、安全区偏好。

### 5. 稳定性修复（重要）
- **退出崩溃 c0000005 已根治**：退出前执行"关投影 → 清通道 → 移除画布场景 → 释放画布 → **`obs_wait_for_destroy_queue()` 排空销毁队列**"，
  彻底避免画布场景/源的延迟销毁与 `obs_shutdown` 竞争（详见 `docs/ADR-记录.md` 的 ADR-005）。

## 三、怎么运行

1. 可执行文件：`D:\HuafeirongOBS\obs-src\build_x64\rundir\RelWithDebInfo\bin\64bit\obs64.exe`
2. 建议加 `--portable` 启动（配置写在运行目录旁，不污染系统用户目录）
3. 走一遍最小验证：新建画布 → 填测试色/给场景加色块 → 选屏编号投影 → 双击画布行快速上屏 → 正常退出 → 重启看是否自动还原

## 四、当前限制（务必知悉）

| 项 | 说明 |
|---|---|
| 画布 API 状态 | 上游 `obs_canvas` 仍标记为 **早期/unstable**；本项目锁定 **32.2.2** 基线，随上游演进评估升级 |
| 内容来源 | 目前画布内容支持：镜像主场景（克隆）、**测试色块演示**；完整"任意源/滤镜/媒体池进入画布"在后续里程碑 |
| 音频 | 演示画布未开启 `MIX_AUDIO`（避免重复出声）；**每路输出独立混音**在生产里程碑实现 |
| 输出类型 | 当前"投影到屏"= 全屏克隆窗；**推流/录制绑定画布**的输出面板尚未实现（规划中） |
| 性能 | 现开发机（Ryzen5 3500U + Vega8 核显）务实档：2 路 1080p60 全帧率 + 1 路推流；正式演出建议独显台式（见技术文稿 §11） |
| 持久化范围 | 场景"内容"目前仅还原测试色块；用户后续通过正式源管理添加的内容在后续里程碑纳入存档 |

## 五、功能预告（Roadmap）

### 近期（当前推进）
1. **切换台作用域闭环**：选中画布后，主界面切换台/热键直接作用于该画布（预览-节目、Cut/Auto、转场按画布独立）
2. **输出绑定面板**：每条推流/录制可绑定到指定画布（多画布多路推流），含码率/丢帧/断流自愈
3. **克隆并入矩阵格**：矩阵格内直接预览+拖出为独立全屏窗；克隆支持裁切/缩放/安全区/LUT 色差校正

### 中期
4. **音频出局路由**：每路输出/流独立选混音（现场屏=现场声、直播=现场声+解说）
5. **PPT 讲者模式**：LibreOffice 渲染 pptx → 主屏放幻灯 + 讲者窗（备注/下一页）+ 翻页笔控制
6. **导播切换台**：按钮矩阵、Cut/Auto、转场预设（Fade/白黑场/滑入/Stinger）
7. **一键回放/慢动作**、**倒计时/时间码上屏**、**推流健康监测与自动重连**

### 后期
8. **素材库/媒体池**：导入整理即拖即用、循环/播放列表/定时切入
9. **开放控制**：obs-websocket 扩展画布语义（`list_canvases/bind_sink/switch`）+ OSC/MIDI（预留）
10. **多屏布局引擎**：布局命名保存/一键还原；**打包发布**（安装包 + 源码开源，GPL-2.0）

## 七、反馈方式

试用后请告知：**操作序列 + 现象**（黑屏/无响应/崩溃弹窗），若崩溃请附
`C:\Users\<用户名>\AppData\Roaming\obs-studio\crashes\Crash *.txt` 的最新日志——
崩溃栈能直接定位到 obs.dll 的具体函数，历史上两次退出崩溃都是靠它精确修复的。
