## 方式 A（推荐，最快跑起来）

```bash
git clone --recurse-submodules -b hfr-snapshot https://github.com/huarongfei/HuafeiRongOBS-obs.git
```

> `hfr-snapshot` 是**快照分支**（单提交，含全部代码；子模块必须一起拉，否则缺 libdshowcapture 等会 configure 失败）。
> 若已 clone 忘了子模块：`git submodule update --init --recursive -- deps/libdshowcapture/src plugins/obs-websocket plugins/obs-browser`

### 构建（Windows）
前置：Visual Studio（含 MSVC + Windows SDK）、CMake ≥3.28、Ninja、Git。
首次 configure 会**自动下载依赖**（prebuilt obs-deps + Qt6，约 1.5~2GB，来自 obsproject/obs-deps）：

```powershell
cmake --preset windows-x64 -DENABLE_BROWSER=OFF
cmake --build build_x64 --config RelWithDebInfo --target obs-studio --parallel 8
```

运行：

```
build_x64\rundir\RelWithDebInfo\bin\64bit\obs64.exe --portable
```

## 试用速览（构建完成后）

1. 启动 `obs64.exe --portable`
2. 右侧 **「输出矩阵（画布）」** 面板：新建画布（名称+分辨率）→ 给场景加色块 / 填充测试色 → 选显示器编号 `▶投影选中屏`（或**双击画布行**投主屏）
3. 选中画布后，面板下方「场景（当前画布）」可新建/切换/删除场景、给场景加色块；`安全区` 给投影叠加 90%/80% 参考线
4. 退出重启：画布、场景集与当前场景、投影布局、安全区偏好自动还原（存于 profile 目录 `hfr_canvases.json`）

功能细节与限制见：`docs/功能预告.md`；技术总纲：`docs/技术文稿.md`；踩坑与决策：`docs/ADR-记录.md`。
